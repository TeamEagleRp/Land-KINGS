# MG / Land Kings - Discord Admin System

التعديلات:
- تسجيل الدخول عبر Discord OAuth2 يحدد Discord User ID والاسم والصورة والدور.
- المسؤول العادي (admin) يظهر له نموذج إضافة الإنجازات.
- المسؤول الأعلى (superadmin) يظهر له الإدارة العليا وسجل العمليات.
- كل إضافة/حذف/إدارة تتم من السيرفر تُسجل في logs.
- سجل العمليات محمي من السيرفر ولا يظهر إلا للمسؤول الأعلى.
- حذف الإنجازات أصبح للمسؤول الأعلى فقط؛ المسؤول العادي يستطيع الإضافة فقط.
- كل إنجاز جديد يحفظ معه منفذ العملية وDiscord ID ويظهر ذلك في بطاقة الإنجاز.

## إعداد التشغيل
1. انسخ `.env.example` إلى `.env`.
2. ضع Discord Client ID وClient Secret وCallback URL.
3. ضع `SUPER_ADMIN_IDS` لآيدي المسؤولين الأعلى.
4. ضع `ADMIN_IDS` لآيدي المسؤولين العاديين.
5. نفّذ:
   npm install
   npm start

مهم: الصلاحيات تعتمد على Discord User ID وليس username لأن الـusername يمكن تغييره.
